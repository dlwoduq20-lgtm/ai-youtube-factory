# AI YouTube Factory — 만평 쇼츠

정치·외교·젠더 등 사회 이슈를 **만화풍 만평 + 모션그래픽** 세로 쇼츠(1080x1920, 30fps)로 만드는 코드 기반 생성기입니다.
외부 이미지/음원 없이 도형·텍스트·효과음을 전부 코드로 그려서 저작권 걱정이 없습니다.

"혹시… 남자 친척은 없으세요?")으로 시작 → SNS 사연 → 장녀의 반박 → 비슷한 경험담 → 장사법 연고자 순위(자녀, 성별 구분 없음)·
2023 대법원 제사주재자 판례 → 관습 vs 가족의 선택 → ① / ② 투표 → 장례지도사의 같은 질문으로 루프.

```bash
TTS_BACKEND=edge python render.py ep07_chief_mourner
```

## 샘플 4: `samples/ep04_secret_deal.mp4` (약 35초) — 새 캐릭터 '두둥실'

**오늘의 만평 #04 — 비밀로 하자며?!**

실제 사건 기반: 9/23 우크라이나 대통령의 유엔총회 연설 속 "북한군 포로 2명 한국 송환" 공개 →
한국 "비공개 합의 위반" vs 우크라이나 "그런 합의 없었다" → 9/28 대사대리 초치, 10/2 공개 사과 요구 →
10/8 주우크라이나 대사 본국 소환(대사관은 계속 운영) → 우크라이나 "대화의 문은 열려 있다".

캐릭터는 채널 고유 스타일 `cartoon_shorts/doodle.py` 의 **두둥실**: 몸에서 살짝 떠 있는 둥근 네모 머리,
막대 팔다리 + 동그란 손, 세로 점 눈 + 굵은 눈썹, 볼터치. `squire.Person` 과 같은 `draw()` 인터페이스입니다.

```bash
TTS_BACKEND=edge python render.py ep04_secret_deal
```

## 샘플 3: `samples/ep03_marriage_license.mp4` (약 31초)

**오늘의 만평 #03 — 결혼에도 자격증이 필요해?**

실제 화제 기반: 중국 72세 교수의 "적어도 3분의 1은 결혼에 적합하지 않다"(3년 전 인터뷰, 9월 말 재확산) 발언 논쟁 +
중국 상반기 혼인신고 7.5% 감소 + 한국 미혼 스몰웨딩 55.2%·노웨딩 13.4%(PMI 2026 웨딩 인식 조사).
결혼 자격증 → 교수(안경, 혼자 느리고 낮은 목소리) → 결혼 필수 능력 체크리스트 → 연애 적정 나이 달력 "40세?!" →
공감파 vs 반박파 → 혼인신고 하락 화살표 → 한국 결혼식 선호 막대그래프 → 댓글 유도.

```bash
TTS_BACKEND=edge python render.py ep03_marriage_license
```

## 샘플 2 (해설 애니메이션 스타일 + TTS): `samples/ep02_who_did_it.mp4` (약 37초)

**오늘의 만평 #02 — 법안이랑 기업 문건이 토씨까지 똑같다고?**

실제 사건 기반: 2026년 10월 6일 산업통상부 국정감사에서 한 야당 의원이 RE100(재생에너지자립도시) 특별법과
한 기업의 내부 문건이 일정·조문까지 일치한다며 입법로비 의혹을 제기한 건. 의혹은 '의원 주장'으로만 다루고
장관 답변("다른 법안을 보고 만든 것으로 추정")과 기업 반론("불법·특혜 없었다")을 함께 넣었으며,
개인·기업 실명은 쓰지 않고 화면 상단에 출처 고지 문구를 표시합니다.

> 프록시/사내망 환경에서 Edge TTS 가 인증서 오류로 실패하면 `SSL_CERT_FILE` 에 CA 번들 경로를 지정하세요 (edge-tts 가 자체 certifi 번들만 쓰기 때문에 `tts.py` 가 해당 CA 를 추가로 신뢰하도록 처리).

해설 애니메이션 쇼츠 스타일: 풀스크린 일러스트, 흰 동그란 얼굴 캐릭터, 차분한 슬레이트·카키 톤,
나무판 벽 배경, 화면 중앙의 큼직한 단어 단위 자막, 천천히 밀고 들어가는 카메라.

- **TTS 내레이션 + 캐릭터 대사**: 내레이터(반말, InJoon), 야당 의원(Hyunsu), 장관(InJoon 저음·덤덤) — Edge 신경망 음성. 속도 +80~85%, 피치를 1.18~1.25배 올린 빠르고 높은 만화 톤, 장관만 낮고 느리게 대비 (`VOICE` 에서 조절). 대사 길이에 맞춰 샷 타이밍이 자동 배치됨
- **립싱크**: 각 화자 음성의 음량 엔벨로프로 입 모양을 움직임
- **장면**: 국회 외경 → RE100 특별법 → 기업 내부 문건 등장 → 야당 의원 "토씨까지 똑같다" → 문건 속 일정 달력(25.10 발의!) → 법 통과 전 예산 206억 → 장관 덤덤한 답변 → 의혹 vs 우연 줄다리기 → 문건·법안 비교 "의혹" 도장 → 양측 입장 + 댓글 유도
- 자막은 화자별 색상(내레이션 흰색 / 의원 민트 / 장관 살구)

```bash
python render.py ep02_who_did_it          # Edge TTS → 구글 TTS → espeak 순으로 자동 폴백
TTS_BACKEND=edge python render.py ep02_who_did_it     # Edge 신경망 음성 강제 (현재 샘플)
TTS_BACKEND=google python render.py ep02_who_did_it   # 구글 TTS 강제
TTS_BACKEND=espeak python render.py ep02_who_did_it   # 오프라인 기계음
```

대본은 `episodes/ep02_who_did_it.py` 의 `SCRIPT` 리스트만 수정하면 됩니다: `(샷 이름, [(화자, TTS 문장, 자막 문장)], 옵션)`.

## 샘플 1 (만평 패널 스타일): `samples/ep01_gridlock.mp4` (31초)

**오늘의 만평 #01 — '협치'는 어디에?**

| 시간 | 장면 | 모션 |
|---|---|---|
| 0–2s | 헤더 "오늘의 만평" 도장, 패널 오픈 | 스케일 슬램, 오버슈트 팝 |
| 2–8s | A당·B당 의원이 '민생법안' 줄다리기 | 슬라이드 인, 팻말 바운스 낙하, 사인파 줄다리기 |
| 8–14s | 팻말이 찢어지며 밧줄에 묶인 '국민' 등장, 물가·집값·금리 가격표가 머리 위로 쌓임 | 중력 낙하, 바운스, 스트레치, 줌인 |
| 14–20s | VS 클로즈업 "전부 저쪽 탓!" / "아니, 저쪽 탓!!" → '탓!' 폭주 | 대각 분할, 집중선, 카메라 셰이크, 파티클 |
| 20–26s | 달력 D+365 넘어가고 "처리된 민생법안: 0건", 밧줄이 끊어지며 정치인들 날아감 → 국민 "그래서 제 월급은요?" | 페이지 플립, 블링크, 버스트, 포물선 |
| 26–31s | 엔딩: "여러분의 생각은?" 댓글 유도 + 구독 버튼 클릭 | 아이리스 트랜지션, 커서 클릭, 종 흔들림 |

- 특정 정당을 지칭하지 않도록 가상의 **A당/B당**, 실제 정당과 겹치지 않는 청록/자홍 색을 사용했고, 하단에 풍자 고지 문구를 넣었습니다.
- BGM(코믹 마림바+베이스)과 효과음(팝, 휘익, 쿵, 툭, 띠링, 타자음)은 `cartoon_shorts/audio.py` 에서 절차적으로 합성합니다.
- 자막은 타자기 효과로 등장하고, 쇼츠 UI(하단 제목·우측 버튼)에 가리지 않도록 화면 중앙 하단에 배치했습니다.

## 실행

```bash
pip install -r requirements.txt      # ffmpeg 필요
python render.py ep01_gridlock                    # → samples/ep01_gridlock.mp4 (약 30초 소요)
python render.py ep01_gridlock --stills 5,15,25   # 특정 시각 스틸컷 PNG
```

## 구조

```
cartoon_shorts/
  engine.py      # 이징, 한글 텍스트 캐시, 말풍선/집중선/버스트/망점 등 모션그래픽 프리미티브
  characters.py  # 캐리커처 정치인(표정·포즈·당 배지), 시민 캐릭터
  audio.py       # BGM/효과음 합성 + 믹싱
  tts.py         # TTS (edge-tts → 구글 → espeak-ng 폴백, 캐시)
  squire.py      # 해설 애니메이션 스타일 캐릭터/배경/소품
  explainer.py   # 해설 쇼츠 공용 틀 (TTS 타임라인, 립싱크, 자막, 전환, 믹싱, 클로즈업)
  doodle.py      # 채널 고유 캐릭터 '두둥실'
  episodes/
    ep01_gridlock.py   # 에피소드 = 타임라인(장면 함수) + 자막 + 효과음 큐
render.py        # 프레임 → ffmpeg 파이프 → mp4
branding.py      # 채널 프로필/배너 이미지 → samples/branding/
```

새 이슈(외교, 젠더 등)는 `episodes/` 에 파일을 하나 추가해 `TITLE`, `DURATION`, `cues()`, `render_frame(ctx, t)` 만 구현하면 됩니다.
캐릭터 색·배지(`Politician(color, badge)`)를 바꾸면 국가 정상(외교), 다양한 시민 캐릭터 등으로 재사용할 수 있습니다.
